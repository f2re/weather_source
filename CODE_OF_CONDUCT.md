# Code of Conduct / Правила взаимодействия

This project is a technical knowledge base. Contributions and review should stay focused on evidence, reproducibility and engineering usefulness.

## Expected behavior

- Be precise about what was verified and what remains uncertain.
- Critique data, code and documentation rather than people.
- Cite official/provider documentation when correcting technical claims.
- Respect differing levels of experience and explain specialist meteorological terminology when needed.
- Keep discussions relevant to the source, protocol, format, implementation or data-quality question at hand.
- Do not publish private credentials, personal information or access details that are not intended to be public.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate disruption, doxxing, credential exposure, spam and knowingly falsified technical information are not acceptable.

## Enforcement

Maintainers may edit, hide or remove comments and contributions that violate these rules, and may restrict participation for repeated or serious violations. Security-sensitive material should be handled according to `SECURITY.md`.
